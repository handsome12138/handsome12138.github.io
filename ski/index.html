首选 / Recommended

T979 雪场直通车

从龙嘉机场一站直达北大湖，车内设雪板存放区。上一雪季全程约 2 小时，原价 ¥80/人、推广价 ¥66/人。可在“吉林市机场巴士”微信服务号购票，也可到 T2 到达层购票。

约 2 小时¥66—80/人适合带雪具
省心 / Door to door

预约包车或网约车

机场到雪场约 126—132 公里，正常车程约 2 小时。五座车历史参考约 ¥400/车，春节、夜间和降雪天气可能上涨；建议提前预约，并确认车辆能放下雪板。

约 2 小时约 ¥400/车多人更划算
兜底 / Backup

先到吉林市再转车

没赶上直通车时，可先乘龙嘉机场至吉林市的城际公交，再从吉林市打车或换雪场接驳。机场至吉林市公交上一季为 ¥18/人、约每小时一班；带雪具换乘会比较折腾。

耗时更长机场段 ¥18/人仅作备用
两套方案都能和上一雪季班车衔接： 上海去程 09:55 落地，可参考 11:00 的机场发车班次；杭州去程 10:25 落地，拿雪具后更建议等 13:30 班次。返程上海可参考 08:00 从北大湖出发的班次，杭州可参考 11:20 班次。目前尚未查到 2026—2027 雪季正式时刻，春节班次务必在出发前通过官方渠道复核并提前买票。

03 / Before

行前先把钱
花在刀刃上

装备不需要一味追求贵，合适、舒服、方便，通常比参数堆满更重要。下面这些建议主要来自我自己的使用感受：品牌只是参考，喜欢的外观和适合自己的尺寸也很重要。

My verdict / 我的结论

  • 基础必买：雪镜、手套和雪袜
  • 最值得投入：一双自己的雪鞋
  • 最好用的设计：袖子上的雪卡袋
  • 护具：单板建议护臀，双板不用额外买
04 / Gear

先看怎么选，
再去搜参考款

链接怎么用 按钮会直接打开淘宝或闲鱼的关键词搜索页，不绑定某个容易下架的 SKU。先按介绍确认尺寸和结构，再比较销量、评价与退换政策。
GEAR 01基础必买

雪镜

介绍 / How to choose

先看头盔兼容和防雾，再看外观。至少选双层镜片、防雾涂层和柔软贴脸海绵；戴框架眼镜就搜标注 OTG 的大框款，镜腿不能被两侧挤压。长期滑更推荐隐形眼镜，或者使用蝴蝶镜。只买一副时，中等透光率或可换镜片会更通用，现阶段不必追昂贵品牌。

参考链接 / Shop预算 ¥100—300
淘宝 · OTG 大框雪镜 淘宝 · 近视蝴蝶镜
搜索词：OTG、大框、双层镜片、防雾；下单前确认能否与自己的头盔无缝贴合。
GEAR 02注意通风

头盔

介绍 / How to choose

先量眉毛上方一圈的头围，戴好后摇头不晃、太阳穴不压、下巴带能塞进一到两根手指。基础款两三百元可以用，我买的是 COPOZZ；更在意旋转冲击保护可以看 MIPS。北大湖滑久了容易热，优先选旋钮调节、可开关通风孔、后部带雪镜固定扣的款式。

参考链接 / Shop预算 ¥200—500+
淘宝 · COPOZZ 可调通风 淘宝 · MIPS 头盔
安全装备尽量买全新；收到后连同雪镜一起试戴，确认额头没有明显空隙。
GEAR 03基础必买

手套

介绍 / How to choose

重点是防水、腕口不进雪、手指能自然握拳。单板经常撑地，建议选内置或可拆护腕的款式；双板更需要灵活握杖，选五指款并确认腕部有防丢挂绳。长腕口套在袖口外更防风雪，北大湖怕冷可以再加薄内胆手套。

参考链接 / Shop参考 ¥80—250
淘宝 · 单板护腕手套 淘宝 · 双板挂绳手套
我用过 COPOZZ、迪卡侬和凯夫拉款；品牌不是重点，护腕结构和合手更重要。
GEAR 04基础必买

雪袜

介绍 / How to choose

雪袜要高过雪鞋筒，优先速干化纤或美利奴混纺；脚底、脚踝和胫骨适度加厚即可，不是越厚越保暖。一次只穿一双，褶皱或双层袜会压脚、磨脚，也会影响雪鞋的包裹和控制。

参考链接 / Shop参考 ¥30—100 / 双
淘宝 · 速干滑雪袜 淘宝 · 美利奴滑雪袜
按脚码选，不要为了保暖买得过厚；雪鞋合脚时，中薄袜通常更舒服。
GEAR 05北大湖保暖

护脸

介绍 / How to choose

普通天气用顶部带抽绳或耳挂的半包即可，薄、好摘，也不容易把呼气导进雪镜；习惯嘴巴呼气，就选口鼻区域有网眼或做薄的款式。北大湖低温和大风天建议备一只全包头套，保暖明显更强，但室内和春雪天气会偏热。

参考链接 / Shop参考 ¥20—100
淘宝 · 半包透气护脸 淘宝 · 全包保暖头套
半包容易滑落时，优先选耳挂、魔术贴或可收紧结构；别让上沿顶到雪镜形成雾气。
GEAR 06 / TOP PICK强烈建议

买一双自己的雪鞋

介绍 / How to choose

这是最值得认真试穿的装备。站直时脚趾可以轻触鞋头，屈膝后脚趾压力减轻、脚跟仍被稳稳锁住，才算合适；不要为了“舒服”故意买大。新手从偏软到中等硬度开始更容易控制。我和怜儿买的是 Atomic，新鞋约两千元；二手重点检查内胆塌陷、鞋壳裂纹、卡扣和鞋底磨损，尺寸必须先试清楚。

参考链接 / Shop全新约 ¥2,000 · 二手几百元
淘宝 · Atomic 双板雪鞋 闲鱼 · Atomic 二手雪鞋
链接只用于找型号和比价；雪鞋不建议完全盲买，最好先在线下试到明确尺码、楦宽和硬度。
GEAR 07单板建议护臀

护具

介绍 / How to choose

双板初学通常不用专门买护具；单板建议优先买护臀，覆盖尾椎、坐骨和两侧髋部，摔倒时更安心。选分片式、能随动作弯折、穿进雪裤后不明显卡裆的款式；EVA 够轻便，想要更薄且吸收冲击更好可以看 D3O 类材料。手腕也容易受伤，可再搭配护腕或带护腕的手套。

参考链接 / Shop参考 ¥80—300+
淘宝 · 单板滑雪护臀 淘宝 · D3O 护臀 淘宝 · 滑雪护腕
护臀要按腰围选码，并确认能塞进现有雪裤；太厚会影响屈髋和坐缆车。
05 / Layers

从里到外，
三层就够了

01 / Base layer

速干衣

介绍 / How to choose

贴身层的任务是排汗，不是越厚越好；避免纯棉，优先速干化纤或美利奴羊毛。我会直接选 UTO，一套一百多，买两套方便五天轮换。

参考链接 / Shop约 ¥100—200/套
淘宝 · UTO 速干套装
02 / Mid layer

抓绒

介绍 / How to choose

中层负责锁住空气保暖。抓绒比厚卫衣更轻、排汗也更快，领口不要高到顶住护脸，袖口也别厚到塞不进雪服。我推荐 AWKA 抓绒，我买的是 166 元；北大湖怕冷可以选中厚款，室内冰箱则薄款更舒服。

参考链接 / Shop参考 ¥150—300
淘宝 · AWKA 抓绒 淘宝 · 滑雪中层抓绒
03 / Shell

雪服上衣

介绍 / How to choose

外层主要挡风、防水。袖口雪卡袋最实用，其次看腋下通风拉链、防风裙、帽子能否套住头盔，以及抬手时衣摆会不会被带起。我推荐雪否，白色那件四百多；北大湖优先保暖和防风，单板款可以更宽松。

参考链接 / Shop参考 ¥400+
淘宝 · 雪否滑雪服 淘宝 · 袖卡袋滑雪服
雪服的小细节

袖子上的拉链雪卡袋最值得优先找，过闸机不用翻口袋；双向主拉链、腋下通风和内置雪裙也会明显提升体验。

淘宝 · 雪卡袋款
裤子怎么选

双板裤合身、蹲起不卡即可；单板裤要给护臀留空间，裤长和臀腿围都稍宽松一些。两百元左右已经有不少选择，先确认裤脚有雪套和耐磨补强。

淘宝 · 双板滑雪裤 淘宝 · 宽松单板裤
